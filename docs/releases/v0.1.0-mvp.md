# MLflow-Monitor MVP (`v0.1.0`)

`v0.1.0` is the immutable public snapshot of MLflow-Monitor's shipped
`create -> prepare -> check` workflow. It preserves the portfolio artifact and
executable fraud-monitoring demo independently of later development on `main`.

## Included Scope

- explicit first-run baseline bootstrap
- pinned-baseline reuse for later Monitoring Runs
- comparability outcomes of `pass`, `warn`, and `fail`
- monitoring-owned MLflow state and `outputs/result.json` evidence
- an executable demo backed by checked-in model and dataset assets
- read-only treatment of Source Training Runs

The MVP ends at `lifecycle_status=checked`. Analyze, close, metric diffs,
findings, and explicit LKG management are not part of this release.

## Reproduce the MVP

```bash
git clone https://github.com/shizheng-rlfresh/mlflow-monitor.git
cd mlflow-monitor
git checkout v0.1.0
uv sync
```

Continue with the
[tagged demo walkthrough](https://github.com/shizheng-rlfresh/mlflow-monitor/blob/v0.1.0/demo/README.md).
Do not use the mutable `main` branch as the installation target for this demo.
