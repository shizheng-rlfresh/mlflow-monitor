# MVP Demo

The executable fraud-monitoring demo is preserved in the immutable
[`v0.1.0` MVP Release](https://github.com/shizheng-rlfresh/mlflow-monitor/releases/tag/v0.1.0).
It is not maintained on the active development line while the v0 product scope is
being implemented.

To run the exact MVP Demo:

```bash
git clone https://github.com/shizheng-rlfresh/mlflow-monitor.git
cd mlflow-monitor
git checkout v0.1.0
uv sync
```

Then follow the
[`v0.1.0` demo walkthrough](https://github.com/shizheng-rlfresh/mlflow-monitor/blob/v0.1.0/demo/README.md).

The demo scripts, checked-in assets, screenshots, and demo-specific tests remain
available at that tag. A replacement demo will be added to the active development
line after the v0 implementation is complete.
